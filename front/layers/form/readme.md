# Слой form
Как устроен слой · 05.10.2026

Формы сайта и отправка заявок: заказ звонка, обратная связь, отклик. Пара к модулю `form`
бэкенда: формы заводятся в админке, сайт находит их по коду. Зависит только от `core`.

## Как пользоваться

```ts
const { detail, error, isSent, trap, upload, submit, clearFieldError } = useSiteForm('callback')
await upload(file)                              // если форма принимает файлы
await submit({ name, phone, captcha, data })    // остальное — само
clearFieldError('phone')                        // на ввод в поле: его ошибка гаснет
```

Описание формы, токен и вопрос капчи загружаются сами. Разобранные на переменные, значения
работают в шаблоне без `.value` — образец формы в демо-сайте, `.playground/app/pages/index.vue`.
Две формы на странице — `const callback = useSiteForm('callback')`, в шаблоне — `callback.trap.value`.

- `detail` — что показывать: какие поля обязательны (`required_field_list`,
  `is_contact_required`), капча и её вопрос, можно ли прикладывать файлы.
- `error` — `ApiError`: `message` пользователю, `fieldMap` под полями.
- `clearFieldError(name)` — на ввод в поле (`@input` или `@update:model-value`): подсветка
  поля гаснет, пока его исправляют. Ошибка, общая для нескольких полей («Укажите телефон или
  email»), гаснет на всех сразу. Новые ошибки — после следующей отправки.
- `isSent` — заявка ушла. Форма сразу получает новый токен, можно отправлять ещё.
- `trap` — значение ловушки для ботов. В разметке формы — `<FormTrap v-model="trap" />`:
  поле «website» за краем экрана. Человек его не видит, по Tab на него не попасть, экранный
  диктор его пропускает, браузер не автозаполняет. Бот заполняет всё подряд — и его заявка
  молча уходит в спам: сохраняется со статусом «Спам», без письма, а боту приходит обычный
  ответ. Имя `website` выбрано заманчивое для бота; `email`, `phone`, `company` не годятся —
  их заполнит автозаполнение браузера, и в спам уйдёт живой человек.

## Что делается само

- **Токен формы и файлы.** Токен одноразовый, файлы привязаны к нему. После отправки,
  а также после ошибок «форма устарела», «уже отправлена», «капча не пройдена» форма берёт
  новый токен. После ошибок полей — нет: иначе пропадут загруженные файлы.
- **Ошибки полей** бэкенд отдаёт `422` по полям — они в `error.fieldMap`: `name`, `phone`,
  `email`, `message`, `captcha`. Показывать под полем; «нужен телефон или email» приходит
  на оба поля сразу.
- **Ловушка по времени.** Бэкенд считает ботом форму, отправленную быстрее чем через 3 секунды
  после загрузки. Человек, вставивший телефон из буфера, может успеть быстрее — `submit`
  дожидается сам: сколько ждать, бэкенд сообщает в описании формы (`fill_seconds_min`).
- **Откуда пришёл посетитель.** При каждой загрузке сайта плагин запоминает сайт-источник
  и первую страницу с параметрами — метки из неё разберёт бэкенд. Правило как у Метрики:
  новый заход с чужого сайта или с метками затирает старый источник, прямой заход — нет,
  пока старому меньше 30 дней. ID посетителя в Метрике берётся из куки `_ym_uid` при отправке.
- **Страница отправки** — текущий адрес.

## Что стоит знать

- **Форма грузится сама, в браузере** — когда компонент появился (`onMounted`), а не при
  серверном рендере: иначе браузер получил бы её второй раз с другим токеном и вопросом капчи,
  а отсчёт 3 секунд пошёл бы от рендера на сервере. Поэтому `useSiteForm` — только в `setup`
  компонента. Загрузить заново — `load()`: не вышло — `detail` остаётся прежним, ошибка — в `error`.
- **Новый токен — по коду ответа, не по тексту:** после 406 (форма устарела, заявка уже
  отправлена, форма выключена) и после ошибки в поле `captcha` слой запрашивает форму заново.
  Тексты ошибок бэкенд может менять свободно.
- **Капча Яндекса** (`captcha_provider: 'yandex'`) — компонент `FormSmartCaptcha`:
  `<FormSmartCaptcha v-model="fields.captcha" :sitekey="detail.captcha_client_key" :form-token="detail.token" />`.
  Скрипт Яндекса грузится, только когда такая капча есть на странице. Токен виджета одноразовый:
  новый токен формы — после отправки или ошибки капчи — сбрасывает виджет сам. Значок SmartCaptcha
  не прятать: Яндекс требует сообщать посетителям, что их данные обрабатывает капча.
- **Цель в Яндекс Метрике.** Отправленная заявка — цель `form_<код формы>` (`form_callback`),
  если на сайте включён счётчик (слой `core`). Цель с тем же именем завести в кабинете Метрики.

## Шпаргалка

- `useSiteForm(код)` → `upload` → `submit`; форма грузится сама, `clearFieldError` — на ввод в поле.
- `<FormTrap v-model="trap" />` — обязательно в разметке формы.
- Ожидание 3 секунд, новый токен и источник визита — делает слой.
