# Исходные сведения учебного сайта
Вымышленный набор · версия 1 · 16.11.2026

ООО и сценарий вымышлены; `example.com` не является обследованным сайтом. Значения ниже — единственный вход текущего прохода. `НУЖНО УТОЧНИТЬ` обозначает отсутствующее сведение: переносите его целиком, не заменяйте догадкой. ИНН необязателен для этого упражнения, не задан и не выводится из названия.

| Маркер | Значение для подстановки |
|---|---|
| operator | ООО «Пример» |
| address | НУЖНО УТОЧНИТЬ: адрес оператора |
| site | https://example.com |
| email | privacy@example.com |
| purpose | ответ на обращение через форму обратной связи |
| people | посетители, отправившие форму обратной связи |
| data | имя, email, текст сообщения; НУЖНО УТОЧНИТЬ: фактический состав технических данных (IP, браузер, страница, источник визита, метки, ID Метрики) и необходимость каждого поля для цели |
| operations | сбор, запись, хранение, использование для ответа; НУЖНО УТОЧНИТЬ: способы обработки, передача, уточнение, блокирование и удаление |
| basis | НУЖНО УТОЧНИТЬ: применимое основание обработки для этой цели и необходимость согласия |
| recipients | НУЖНО УТОЧНИТЬ: круг сотрудников, привлечённые обработчики и иные получатели, передаваемые данные и условия передачи |
| location | НУЖНО УТОЧНИТЬ: системы, владельцы хранилищ и страны для основной базы, почты, журналов, очередей, резервных и внешних копий |
| retention | НУЖНО УТОЧНИТЬ: сроки и условия прекращения обработки, удаления основных данных и копий; автоматического срока заявок шаблон не задаёт |
| requests | обращение письмом на указанный email; НУЖНО УТОЧНИТЬ: порядок идентификации, сроки ответа, уточнения, блокирования и уничтожения, работа с внешними копиями |
| protection | НУЖНО УТОЧНИТЬ: фактически применяемые меры защиты и ограничения доступа |
| consent_term | НУЖНО УТОЧНИТЬ: срок действия согласия или условие его прекращения |
| withdrawal | НУЖНО УТОЧНИТЬ: порядок отзыва, прекращения обработки после отзыва и сроки, наличие иных оснований для продолжения |
| confirmation | НУЖНО УТОЧНИТЬ: отдельное явное действие человека для этой формы и требуемая форма согласия; дата/IP не сохраняют текст или версию документа |
| choice_storage | localStorage `cookie-choice`: ответ «Принять»/«Отклонить» в браузере; автоматический срок очистки не задан; НУЖНО УТОЧНИТЬ: фактический срок хранения |
| visit_storage | localStorage `form:visit`: источник, первая страница с параметрами и время; слой форм учитывает возраст 30 дней, это не гарантия удаления; сведения уходят с заявкой оператору; НУЖНО УТОЧНИТЬ: срок хранения и дальнейшие получатели |
| analytics | Для учебного сценария выбрана Яндекс Метрика с Вебвизором: анализ посещений и действий, cookie задаёт счётчик, `_ym_uid` может попасть с заявкой оператору; НУЖНО УТОЧНИТЬ: полный состав данных/cookie, сроки, юридические лица получателей, страны и хранилища |
| other_services | НУЖНО УТОЧНИТЬ: подключение SmartCaptcha, почты, Telegram и иных сервисов, их данные, назначение, получатели, сроки и география; кабинет и его cookie в этот сценарий не включены |
| choice_rule | В исходном шаблоне при настроенной Метрике и отсутствии читаемого `declined` счётчик запускается до ответа окна. Успешно сохранённый и прочитанный отказ блокирует собственные события и следующую загрузку счётчика; `form:visit` и чтение оставшегося `_ym_uid` отдельны. Общего действия повторного открытия выбора нет; НУЖНО УТОЧНИТЬ: фактический способ изменения выбора на сайте |

Ручное уточнение для упражнения: после подстановок добавьте в конец `privacy.md` отдельный абзац **«Ручное уточнение: не включать сведения о здоровье и документы в текст учебного обращения.»** Это условие учебного сценария, не доказательство ограничения произвольного поля на сайте.
