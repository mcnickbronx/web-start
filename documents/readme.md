# Юридические страницы
Шаблоны в Markdown · 16.11.2026

Четыре образца для адаптации под свой сайт. Во всех текстах использованы тестовые реквизиты: ООО «Демо», `privacy@example.com` и `https://example.com`.

| Шаблон | Адрес страницы в примере |
|---|---|
| [Политика обработки персональных данных](templates/privacy.md) | `/politika-obrabotki-personalnyh-dannyh/` |
| [Согласие на обработку персональных данных](templates/consent.md) | `/soglasie-na-obrabotku-personalnyh-dannyh/` |
| [Политика использования cookie](templates/cookies.md) | `/politika-ispolzovaniya-cookie/` |
| [Согласие на рассылку](templates/newsletter-consent.md) | `/soglasie-na-rassylku/` |

Скопируйте нужные файлы в свой проект, замените тестовые реквизиты и проверьте перечисленные цели обработки и сервисы по своему сайту. Ссылки внутри текстов используют адреса из таблицы; если страницы находятся по другим адресам, обновите ссылки.

Исходная версия текстов — **1.0**. При изменении сохраняйте предыдущую редакцию и указывайте новый номер версии. Публикация файлов и подключение ссылок в баннере или чекбоксах выполняются в проекте сайта.
